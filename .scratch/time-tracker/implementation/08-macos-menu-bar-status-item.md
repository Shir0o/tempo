# 08: macOS Menu Bar Status Item

Status: ready
Phase: 3 - Desktop macOS
Dependencies: 01, 02

## Scope
Implement the native `NSStatusItem` desktop menu bar item for macOS.

## Deliverables
- Dynamic menu bar title updating live: `[🟢 01:24 Coding]` when tracking, monochrome `[⏱️]` when idle.
- Preferences for display format: Full (`[Dot] [HH:MM] [Name]`), Compact (`[Dot] [HH:MM]`), and Minimal (`[Dot]`).
- Left-click triggers Quick Popover; right-click displays quick menu.
