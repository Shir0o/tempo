# 13: Android Flutter Dashboard and Statistics

Status: ready
Phase: 5 - Mobile & Sync
Dependencies: 01, 02

## Scope
Implement the full mobile dashboard, activity management screens, and daily/weekly statistics in Flutter for Android.

## Deliverables
- Main 1-tap capture grid with custom activity colors, icons, and pinned status.
- Daily and weekly aggregate charts (bar charts, time distribution donuts).
- Manual record editor for adjusting start/end times and comments.
- Tag and category management.
